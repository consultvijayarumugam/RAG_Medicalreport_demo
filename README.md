# Medical Report RAG Assistant

A Retrieval-Augmented Generation (RAG) web application that allows users to upload a medical report (PDF) and ask intelligent questions about it.

**Built as part of Gen AI Architect Program - Assignment 6**

## Features

- PDF Upload & Processing
- Text Chunking + Embeddings using OpenAI
- Vector Search with FAISS
- Natural Language Q&A
- Source document references
- Beautiful & Clean UI

## Tech Stack

- **Frontend**: Streamlit
- **LLM**: OpenAI (gpt-3.5-turbo)
- **Framework**: LangChain
- **Vector Store**: FAISS
- **Embeddings**: OpenAI Embeddings
